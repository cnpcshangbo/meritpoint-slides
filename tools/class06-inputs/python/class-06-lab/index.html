02

Open the actual source

Open the publisher page and codebook. Record the file/version, collection period, population, access terms and what one row represents. Check that the necessary variables exist.

Keep as evidence: A source URL, a readable file or documented access blocker, and meanings/units for three relevant columns.

AI prompt · adapt with my question and actual output

Context: my question is […]; one row means […]; these are my real column names and codebook notes […].

Using only the source page, codebook and column names I provide, check whether this dataset fits my question. Quote the relevant variable names and flag unknown details. Do not invent a download link, license, variable, date or citation. Ask me to open and verify the original source.

03

Inspect before changing

Keep a raw copy. Count rows, columns and parsed missing values; inspect codebook missing-value codes, repeated rows/IDs, types, units and plausible ranges. For images or signals, start with the file/label manifest.

Keep as evidence: Actual output: shape, a missingness table with denominators, a duplicate/key check, and at least one codebook or range check.

AI prompt · adapt with my question and actual output

Context: my question is […]; one row means […]; these are my real column names and codebook notes […].

Help write a small pandas inspection cell for my file. Show the expected output structure, not invented results. Count missing values with row denominators, flag codebook sentinel values separately, and inspect duplicates without dropping them. Explain each line. Preserve the raw file and do not fill, delete, scale or train anything yet.

04

Make one justified decision

Choose keep, flag, transform or investigate. Explain how the decision affects your question. If checks find no issue, keep the data and record what was checked. Repeated observations can be valid; extreme values can be real.

Keep as evidence: One decision log entry: observed issue or “no change”, evidence, rule, affected rows and limitation.

AI prompt · adapt with my question and actual output

Context: my question is […]; one row means […]; these are my real column names and codebook notes […].

Here is my actual audit output and codebook evidence. Offer two reasonable options for this specific issue, including leaving it unchanged when appropriate. Explain which observations each option would affect. Wait for my choice before giving a transformation. Do not assume missing means zero or duplicate means error.

05

Check the AI-assisted result

Inspect three source rows yourself, including a flagged case if one exists. Reconcile all counts. Re-run from a fresh notebook state. Verify the raw file hash is unchanged; a hash proves file identity, not data accuracy.

Keep as evidence: A hand-check that agrees with the code, before/after counts, an unchanged raw file, and one limitation.
