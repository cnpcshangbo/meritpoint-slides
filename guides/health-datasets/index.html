3Ready-to-download datasets, by topic

Curated via our course's own dataset-search API (Hugging Face + UCI + Kaggle) — the same tool behind the ScholarMind topic finder — then hand-checked. Every card links to the dataset's page with license and documentation.

Clinical tabular data · predict a condition from measurements

UCI Heart Disease (Cleveland)

One row = one patient (13 clinical features → disease yes/no)

THE classic first medical-ML dataset; 303 rows, fits every classifier from Class 11–12.

Heart Failure Prediction (Kaggle)

One row = one patient (11 features → heart disease)

918 rows, tidy CSV, superb documentation.

Indicators of Heart Disease — CDC BRFSS extract

One row = one survey respondent (lifestyle + conditions)

400k rows from the real CDC survey — big enough for honest subgroup questions.

Stroke Prediction (Kaggle)

One row = one patient (age, hypertension, glucose… → stroke)

Classic imbalanced-classes lesson: accuracy lies here (Class 11!).

Pima Indians Diabetes

One row = one patient (8 measurements → diabetes)

768 rows; also a lesson in data ethics — read its collection story.

Diabetes 130-US Hospitals (UCI)

One row = one hospital admission (101k encounters)

Real hospital-readmission data — the question pros actually study.

Early Stage Diabetes Risk (UCI)

One row = one patient (symptoms questionnaire → diabetes)

520 rows of yes/no symptoms — a perfect decision-tree dataset.

Breast Cancer Wisconsin (Diagnostic)

One row = one tumor sample (30 cell-nucleus features → benign/malignant)

The benchmark for explaining what features a classifier uses.

Obesity Levels from Eating Habits (UCI)

One row = one person (habits questionnaire → obesity level)

Multi-class target + lifestyle features students instantly understand.

Alzheimer's Disease Dataset (Kaggle)

One row = one patient (demographics, lifestyle, cognition → diagnosis)

2,149 rows, modern and clean.

Drug Reviews — Druglib (UCI)

One row = one patient review (text + 10-point rating)

Text + numbers: sentiment meets side-effects. NLP-flavored posters start here.

Wearables, mobile health & IoT monitoring

FitBit Fitness Tracker Data (Kaggle)

One row = one user-day (steps, calories, sleep, heart rate)

30 real users' exported trackers — minute-level data, many joinable tables.

Apple Watch & Fitbit Data (Kaggle)

One row = one measurement window from two devices

Two devices on the same activities → the device-agreement question.

Human Activity Recognition Using Smartphones (UCI)

One row = one 2.56 s sensor window (561 features → activity)

The canonical phone-sensor dataset: walking vs stairs vs sitting.

WESAD — Wearable Stress & Affect Detection (UCI)

One row = one sensor timestamp (chest+wrist signals, labeled stress/amusement)

Research-grade stress detection — the dataset behind many real papers.

Activity from Chest-Mounted Accelerometer (UCI)

One row = one accelerometer sample (52 Hz, 15 users, 7 activities)

Raw signal → you engineer the features (Class 8 flex).

Activity of Healthy Older People (batteryless sensor, UCI)

One row = one sensor reading from adults aged 66–86

Aging-in-place monitoring — an eHealth topic with real social weight.

Body Postures & Movements — PUC-Rio (UCI)

One row = one reading from 4 body sensors (165k rows)

Five postures, four sensor positions — which sensor matters most?

Biometrics for Stress Monitoring (Kaggle)

One row = one physiological sample during tasks

Compact companion to WESAD.

Sleep, mental health & student life

Sleep Health and Lifestyle (Kaggle)

One row = one person (sleep duration/quality, stress, activity, disorder)

374 rows, instantly chartable — the most poster-friendly starter here.

Student Mental Health (Kaggle)

One row = one student survey response

Small and honest: depression/anxiety vs GPA, year, gender.

Student Depression Dataset (Kaggle)

One row = one student (pressures, habits → depression)

27k rows — big enough for subgroup fairness questions.

Student Stress Factors (Kaggle)

One row = one student (20 stress factors)

Psychological + academic + social factors in one table.

Mental Health in Tech Survey (OSMI, Kaggle)

One row = one tech worker (attitudes + treatment)

Workplace mental health + a masterclass in messy survey cleaning (Class 8).

Music & Mental Health Survey (Kaggle)

One row = one respondent (listening habits + anxiety/depression/insomnia scores)

The teenager-magnet dataset: does music taste track mood?

Medical Student Mental Health (Kaggle)

One row = one medical student (burnout, empathy, support)

Health-workforce wellbeing — an under-asked eHealth angle.

Flaredown — Chronic Illness Symptom Tracker (Kaggle)

One row = one patient-day symptom/treatment check-in

Real patient-generated app data — mHealth in the wild.

Biomedical signals & medical imaging

ECG Heartbeat Categorization (Kaggle)

One row = one heartbeat (187 samples → normal/arrhythmia class)

Pre-segmented beats = signal ML without signal-processing pain.

PTB-XL 12-lead ECG (PhysioNet)

One row = one 10 s clinical ECG (21k records, cardiologist labels)

Open, research-grade, with published benchmarks to compare against.

Sleep-EDF Expanded (PhysioNet)

One row = one 30 s sleep epoch (EEG → sleep stage)

Real polysomnography — the science behind every sleep app.

Chest X-Ray Images — Pneumonia (Kaggle)

One row = one pediatric chest X-ray (normal/pneumonia)

5,863 images; the standard first medical-imaging project.

NIH Chest X-rays (Kaggle mirror)

One row = one X-ray (112k images, 14 disease labels)

HAM10000 Skin Lesions (Kaggle)

One row = one dermoscopy image (7 lesion classes)

10k images incl. metadata (age, site) — imaging + tabular in one.

Retinal OCT Images (Kaggle)

One row = one retinal scan (4 classes)

84k scans from a landmark Cell paper.

Alzheimer MRI (Hugging Face)

One row = one brain MRI slice (4 dementia stages)

Loads in one line of Python via datasets library.

Confused Student EEG (Kaggle)

One row = one EEG sample while watching lecture videos

Can a headset tell you're confused? Education meets eHealth.

Epileptic Seizure Recognition (Kaggle)

One row = one 1 s EEG segment (178 values → seizure/not)

Tabular-shaped EEG: signal ML with a plain CSV.

EEG Brainwave — Feeling Emotions (Kaggle)

One row = one EEG feature window (positive/neutral/negative)

Emotion detection from a consumer headset.

Public health, environment & population data

Our World in Data — Health

Every chart has a CSV download button. Life expectancy, obesity, mental health, vaccination…

WHO Global Health Observatory

One row = one country-year indicator

The official UN numbers behind global-health claims; has a free API.

One row = one examined person (labs, diet, activity, questionnaires)

Real physical-exam microdata — the pro upgrade from Kaggle surveys.

CDC BRFSS

One row = one adult phone interview (400k+/year)

World Health Statistics 2020 (Kaggle bundle)

One row = one country-year indicator (pre-bundled CSVs)

WHO indicators without the portal learning curve.

EPA Historical Air Quality (Kaggle)

One row = one monitor-day pollutant reading (US, 1980s→)

Decades of PM2.5/ozone — join to health outcomes by state/year.

Global Air Pollution (Kaggle)

One row = one city (AQI by pollutant)

23k cities — the map-figure dataset.

Our World in Data — COVID-19 (Kaggle mirror)

One row = one country-day (cases, deaths, vaccinations)

The pandemic as a clean time-series table.

Open Food Facts (Kaggle)

One row = one packaged food product (nutrients, labels)

Crowd-sourced nutrition on 100k+ products — sugar-content questions live here.

NHANES 2013-14 Age Prediction Subset (UCI)

One row = one NHANES respondent (prepared ML subset)

A gentle, pre-cleaned on-ramp to NHANES.
