Preliminary Data Quality & Research Readiness Index (DQI) · 数据质量与研究就绪度 /5

Each of the 57 listed data resources has an editorial integer rating informed by five review considerations. The shelf was reviewed from repository metadata and targeted file checks between August 13–16, 2026. This is not a validated or mechanically additive scale; open “Why?” for the principal limitation. For broad official sources, 5/5 describes source/repository readiness only; for CARLA it describes platform readiness only — the health observations and study protocol remain unscored.

1. Traceable sourceOriginal collector, study, or source chain is identifiable.
2. DocumentationVariables, labels, and collection process are documented.
3. Measurement validityMeasurements or labels have a credible basis for the listed use.
4. Completeness & coverageMissingness, independence, leakage risk, sample, classes, and population are usable.
5. Reproducible accessStable download/version/license supports a repeatable student workflow.

5/5 = strong metadata · 4/5 = good, review the caveat · 3/5 = usable with an audit · 1–2/5 = verify before choosing · N/A = choose a concrete dataset or collection protocol first.

Important: DQI is a screening aid, not a promise of model accuracy, a row-level audit, or proof of causal/clinical validity. For a chosen question, still run the question-specific RIGHT check. The dimensions are informed by WHO's data-quality framework ↗ and FAIR data principles ↗.

How could R2 be negative? · 为什么 R2 会是负数？

R² = 1 − SSE/SST. On held-out data, R² is negative when the model's squared error is larger than the error from always predicting the test-set mean. That is a valid result, not a broken calculator. It can reflect weak signal, a small test set, a person-level distribution shift, inconsistent preprocessing, or model misfit — and does not by itself prove poor data quality. scikit-learn definition ↗

For the Fitbit steps→sleep idea, user coverage differs across tables and days repeat within people. Predeclare one ActivityDate–SleepDay join, estimate a within-person association with participant-cluster uncertainty, and treat a negative R² as an honest possible finding. For a cleaner student rerun, start with QB-02 Human Activity Recognition (DQI 5/5) and hold out participants, or use QA-07 Breast Cancer Wisconsin (DQI 4/5) for a simpler classification workflow. Use ROC-AUC/F1 rather than R² for classification.
