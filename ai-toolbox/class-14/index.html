Warm-up · fair or not?

Quick check · tap an answer

Teaching example: Model A scores 0.91 and Model B scores 0.86. A used one test split; B used a different split. What may you conclude?

A model comparison is a controlled experiment. If both model and test rows change, the cause is confounded. Re-evaluate both on the identical split or identical cross-validation folds.

The scores are a teaching example, not a result. Ask students to name the two things that changed.
Design step 1 · write the claim first

A fair experiment begins as one sentence

On the same data, split, preprocessing and metric, does model B improve F1 over the majority-class baseline?

Independent variable

The one thing you change: model, feature set, or parameter.

Outcome

The metric chosen before results: F1 here.

Controls

Rows, folds, preprocessing, seed and evaluation code.

The sentence is a pre-flight check. If it cannot name the change, outcome and controls, the code will not rescue the design.
Design step 2 · earn the complexity

Every model must beat a baseline

A baseline is the simplest credible rule that answers the same question.

  • Classification: always predict the majority class
  • Regression: predict the training mean
  • Time series: repeat the last observed value

Seeded synthetic teaching data

Majority baseline: accuracy 0.713, recall 0.000, F1 0.000.

It gets 107 / 150 rows right while finding zero positive cases.

High accuracy can be the lazy answer. The baseline tells you how much accuracy was available without learning anything useful.
Numbers are computed from Lab 1's confusion matrix. Do not call the positive class a disease, fraud, or safety event; it is synthetic class 1.
Quick check 2 · baseline

Quick check · tap an answer

Teaching example: a dataset is 72% class 0. An always-class-0 baseline gets 72% accuracy and 0% recall for class 1. Your model gets 74% accuracy and 5% recall. Best interpretation?

Beating baseline is necessary, not sufficient. Report the size and uncertainty of the gain, plus the metric tied to the real error cost.

The percentages are a labeled teaching example. The goal is to reject leaderboard thinking without rejecting measurement.

Pipelinesame preprocessing

Metricsame function

Valid question

Same split and scaler; logistic regression versus SVM; compare pre-chosen F1.

Confounded question

New model, new features, new split, tuned threshold — then credit the model for the whole gain.

A full product change may alter many things, but an experiment must isolate them in stages. Otherwise the result can guide deployment but cannot explain causation.
Design step 4 · lock the rows

The split is part of the experiment

The same logistic model, evaluated on 20 valid stratified splits, produced:

F1 min 0.563 · max 0.737
mean 0.631 ± 0.050

Seeded synthetic teaching data · computed by Lab 1.

The fair pattern

  1. Create one split or fold object
  2. Save the indices
  3. Pass the same indices to every contender
  4. Never keep rerolling until one model wins
The split can move F1 by 0.174. That is larger than many claimed model improvements.
All twenty values come from the identical model and data; only random_state changes. This isolates split noise cleanly.
Quick check 3 · same split

Quick check · tap an answer

Teaching example: KNN uses random_state=7 and SVM uses random_state=42. SVM wins by 0.04 F1. What is the correct next move?

Different random states changed which rows were easy or hard. Freeze the evaluation rows first; tune only inside training data.

Ask what must be saved in a reproducibility folder: split indices or a deterministic fold specification, not just a screenshot of the score.
Failure mode · tomorrow sneaks into training

Leakage makes a model look clairvoyant

Target leakage

A feature is created from the answer or from information available only after the decision.

Train/test contamination

Scaling, imputation, feature selection or duplicate removal sees test rows.

Group/time leakage

The same person appears in both sets, or future events train a past prediction.

Synthetic demonstration: honest five-fold accuracy 0.810; add a near-copy of the label as a feature and it becomes 1.000. The perfect score is the alarm.
The leaked feature is intentionally obvious in figs-class14.py: y plus tiny noise. It demonstrates mechanism, not a realistic benchmark.
Leakage defense · fit inside each fold

Preprocessing belongs inside the pipeline

Wrong

X_scaled = scaler.fit_transform(X)  # all rows
cross_val_score(model, X_scaled, y)

The test fold helped choose its own means and standard deviations.

Right

pipe = make_pipeline(StandardScaler(), model)
cross_val_score(pipe, X, y, cv=folds)

Each fold learns preprocessing from its training rows only.

Split first. Fit transformations second. Apply them to held-out rows third.
This pattern covers scaling, imputation, PCA and feature selection. Deduplication and group/time splitting often need to happen even earlier.
Quick check 4 · leakage

Quick check · tap an answer

Before cross-validation, you fill every missing value using the median computed from the full dataset. What is wrong?

The full-data median contains information from every future validation fold. Put the imputer inside a Pipeline so each training fold learns its own median.

The leakage may move the score only a little; fairness is about process, not whether the shortcut happened to matter this time.

Analysis step 2 · report center and spread

Mean alone hides the unstable fold

Five F1 scores

0.727 · 0.610 · 0.710 · 0.596 · 0.448

F1 = 0.618 ± 0.112

Sample standard deviation across fixed folds · synthetic teaching data.

  • Mean describes typical performance
  • Standard deviation shows sensitivity to which rows were held out
  • Fold scores reveal whether one group is much harder
Do not write “the model scores 0.618” as if it were a law. Write the evaluation design and the spread beside it.
The low fifth fold is intentional evidence of instability. Resist deleting it; investigate its rows.
Quick check 5 · uncertainty

Quick check · tap an answer

Teaching example: Model A has F1 0.72 ± 0.14; Model B has F1 0.70 ± 0.02 on the same folds. Which is the strongest conclusion?

The means alone do not settle the choice. A may win on average, while B is more stable. Inspect paired fold differences and the deployment cost before claiming superiority.

These are teaching numbers. The key word is paired: the folds are the same, so per-fold differences are more informative than two unrelated error bars.
Analysis step 3 · open the score

The confusion matrix names both mistakes

[[ TN 97, FP 10 ],
 [ FN 16, TP 27 ]]

Seeded holdout from Lab 1:

  • 16 false negatives — positive cases missed
  • 10 false positives — false alarms
  • Every other metric is a summary of these four boxes
Always state which class is “positive.” Swapping it changes precision and recall without changing accuracy.
The positive class is deliberately generic synthetic class 1. Ask students to point to the box their project most fears.
Analysis step 4 · match metric to mistake

Accuracy, precision, recall and F1 ask different questions

Accuracy 0.827 — how often was any label right?

Precision 0.730 — when it predicted positive, how often was it right?

Recall 0.628 — of all positives, how many did it find?

F1 0.675 — harmonic balance of precision and recall.

Choose before looking: false negatives costly → emphasize recall; false positives costly → emphasize precision; both matter → report both and perhaps F1.
All four numbers are computed at build time from the displayed matrix. F1 is not a moral compromise; it is a specific harmonic mean that ignores true negatives.
Quick check 6 · metric choice

Quick check · tap an answer

A screening-style task says missing a positive is far costlier than reviewing an extra false alarm. Which metric deserves priority?

Recall measures the fraction of real positives found. Still report precision and the confusion matrix, because high recall can be purchased with too many false alarms.

This is a generic cost structure, not medical advice. The design rule is portable: name the expensive error, then select the metric.
Analysis step 5 · the model gives a score; you choose a rule

Out-of-fold probabilities · same five folds · synthetic teaching data.

Lower threshold: more positives called → recall rises, false alarms rise. Higher threshold: precision rises, misses rise. Retraining is not required.
These are out-of-fold predictions, so threshold selection is not being demonstrated on in-sample probabilities. In a real project, reserve a final untouched test set after choosing the threshold.
Decision rule · write cost before threshold

A threshold is a value judgment written as a number

Before seeing the table

Write: “A false negative costs five times a false positive.” Decide who owns that statement.

Then evaluate

For each threshold: cost = 5 × FN + 1 × FP. Show the full matrix so others can challenge the weights.

The 5:1 cost ratio is a teaching example, not a domain recommendation.

The model estimates probabilities. The project decides what to do with them. Do not hide the second decision inside “the AI chose.”
The 5:1 ratio is explicitly a teaching example. Real weights require domain owners, affected people and often policy or regulation.
Quick check 7 · threshold

Quick check · tap an answer

You lower a classifier's threshold from 0.70 to 0.30. What usually happens?

More cases cross the lower bar, so the model catches more positives and also raises more false alarms. The fitted model is unchanged; only the decision rule moved.

Have students distinguish model training from decision policy. That distinction is the bridge from Class 11 to experiment reporting.

Quick check 8 · the honest sentence

Quick check · tap an answer

Which results sentence is strongest?

The strong sentence names the data, evaluation design, metric, uncertainty and limitation. It reports evidence without turning one experiment into a universal claim.

Reporting · make the claim reproducible

The one-page experiment record

Design

Question · hypothesis · baseline · independent variable · controls · primary metric.

Protocol

Dataset version · exclusions · split/folds · seed · preprocessing pipeline · model settings.

Results

Fold scores · mean ± std · confusion matrix · threshold · limitations · failed runs retained.

Minimum honest sentence: “On [data], using [split/folds], model B changed [pre-chosen metric] from baseline [x] to [y], with [spread]; this does not establish [limitation].”
A screenshot is not a record. Ask for code, saved indices or fold spec, package versions and every contender's result.

Class 15 · evidence checklist

If it is not visible, the audience cannot audit it

  1. Source, version and n
  2. Target + class balance or target range
  3. Baseline + contender
  4. One changed variable + at least 3 controls
  5. Split/folds, seed and preprocessing Pipeline
  6. Pre-chosen metric + why it matches the stakes
  1. Full results table + uncertainty
  2. For classification: confusion matrix; threshold + cost rule if moved
  3. One surprise or failed result
  4. One limitation + one next test
  5. Notebook and data links
  6. AI table: tool/model · used for · how I verified it
AI disclosure: write “No generative AI used,” or name every tool/model, what it helped produce, and the rerun, source check, or correction that made the work yours.
The checklist is deliberately concrete. “We used Kaggle” is not provenance; name the dataset and version. “We controlled everything” is not a design; name at least three controls. An AI-tool logo is not disclosure; the verification action is the important column.

Wrap-up

A trustworthy score has a chain of custody

  • Baseline — earn the complexity
  • Control — same rows, pipeline, folds and metric
  • No leakage — held-out means unseen
  • Uncertainty — folds, mean and spread
  • Error costs — matrix, metrics and threshold
  • Reporting — say what the evidence cannot prove

Exit ticket: name the one variable your experiment changed — and three things it froze.
