3 · Choose the publication lane

The evidence story stays the same; the audience and container can change.

Fastest · no code

Google Sites / Notion / Canva

  1. Create one blank page.
  2. Copy the preview section by section.
  3. Add the focal chart and approved links.
  4. Publish to the intended audience and test access.
Code-forward

GitHub Pages

  1. Download this page and rename it index.html.
  2. Add it to a public, teacher-approved repository.
  3. Enable Pages from the repository settings.
  4. Test the final URL on mobile and in a private window.
Private / reviewer-only

PDF or controlled link

  1. Print the preview to PDF or keep the page behind approved access.
  2. Label unavailable artifacts honestly.
  3. Share only through the application or program's approved channel.
  4. Never trade privacy for polish.

Final two-click audit

A reviewer should identify the question, your role, the supported result and its boundary in ten seconds—and reach the evidence in two clicks or fewer. Put the stable URL in the resume header as Portfolio: https://… and link the project title to the exact project page.
