Quick check · who is doing the labeling?

Quick check · tap an answer

During Player Run, what is the training label for each row?

The current k-NN learns sensor state → human action. Reward is logged for evaluation, not used to train this policy. Every demonstration—including a mistake—is a label the agent may copy.

答案后明确：当前 k-NN 只用 sensor state 与 human action 训练，不根据 reward 过滤样本。因此模型可能继承人的错误；若要用 reward 判断动作好坏，需要人工纠错、reward weighting 或 reinforcement learning，那是另一种方法。

Read code like a scientist · line by line

Every line makes a claim we can test.

01

Contract: one state + demonstration rows → one action.

02

Represent: convert the visible situation to four numbers.

03–05

Compare: square feature differences, sort by distance, keep the nearest nine.

06

Initialize: start LEFT, STAY, and RIGHT votes at zero.

07

Weight: closer examples contribute a larger vote; .025 prevents division by zero.

08

Decide: sort actions by vote and return the winner.

09

Close: finish one inspectable prediction.

Debugging question: If every demonstration says STAY, which line is wrong? None. The data—not the syntax—fails to cover LEFT and RIGHT.
按九行教学版逐步解释：contract、representation、comparison、neighbor selection、vote initialization、inverse-distance weighting、decision。最后用全 STAY 反例强调：代码可以完全正确，但示范数据覆盖不足。完整 production version 还会做 class balancing 并返回 probabilities。

From game to research · turn fun into a test

Our question changes one thing—and fixes the data budget.

With the same 240 demonstration rows, does training on more level seeds improve action accuracy on unseen levels?

Change

1 seed versus 12 seeds in training demonstrations.

Hold fixed

240 rows, four sensors, weighted k-NN, k=9, and the same test seeds.

Measure

Accuracy on 600 expert-labeled actions from 20 unseen seeds; game score as a secondary outcome.

在学习单 Part C 写假设。强调如果多样组有更多数据，我们无法知道提升来自数量还是多样性；所以总行数必须相同。
Experiment design · isolate the cause

Quick check · tap an answer

The 12-seed agent has 2,400 training rows; the 1-seed agent has 240. Can a score difference be attributed to level diversity?

No. Diversity and data amount are confounded. Give both agents the same number of rows, then change only how many level seeds produced them.

用这一题检查 controlled comparison。让学生用一句话说出 independent variable、control 和 outcome。

Open-data extension · real players, licensed source

Can four interpretable sensors retain most of a full telemetry model?

SkillCraft1 · UCI

3,395 StarCraft II player records · 15 behavioral telemetry fields · target is LeagueIndex ≥ 5.

Dataset DOI · Blair, Thompson, Henrey & Chen (2013) · CC BY 4.0

Controlled comparison

4 sensors: APM, hotkey selection, action latency, perception–action cycles.

15 sensors: all behavioral telemetry. Same players, target, model, preprocessing, and five folds.

RQ: How much predictive performance is lost when we use four interpretable sensors instead of all fifteen?

这是外部开放数据，不是虚构样例。说明 target 是 Diamond 到 Professional 的 operational label，不代表完整的人类专长定义。数据脚本会从 UCI 下载原始 CSV，但公开成果包只保存 aggregate outputs。
Executable result · five identical folds

The compact sensor set retained most—but not all—of the signal.

4 sensors

ROC AUC 0.861 ± 0.011
accuracy 77.6% ± 1.3%

15 sensors

ROC AUC 0.879 ± 0.012
accuracy 78.9% ± 1.2%

Mean ± SD across five stratified folds; class-balanced logistic regression; random_state=42. Observed ROC AUC difference: +0.018. Open evidence package

先读 effect size，再谈含义。增加 11 个 sensors 只有 0.018 AUC 增益；这可以引出 accuracy–interpretability trade-off，但不能说某种操作导致高水平。点击 evidence package 可下载 fold-level CSV 和完整脚本。
Open data → extended abstract · exact AI handoff

The prompt carries the evidence boundary into the writing.

Draft Background, Method, Results, Limitations, and Next Experiment. Say “associated with,” not “caused.” Do not invent p-values or confidence intervals. Generated result

Title: How Much Telemetry Is Enough?

Bounded takeaway: four sensors retained most of the discrimination; all 15 produced a modest gain that motivates a sensor-ablation study.

Metric key: ROC = receiver operating characteristic curve, showing the true-positive/false-positive trade-off across thresholds. AUC = area under that ROC curve: 0.5 is chance ranking, 1.0 is perfect ranking. SD = standard deviation, the spread across the five folds.
