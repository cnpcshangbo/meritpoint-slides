Dice showdown
Run a tiny dice game and distinguish a rule from a random result.

    
YOUR MISSION
Run the program several times. Each run rolls one die for you and one for the bot. Then experiment with a different number of sides on your die.
Must the same code show the same rolls each time? What values would a twelve-sided die allow?

    
CHANGE ONE THING
Change only my_sides from 6 to 12. Run several times and record actual rolls, including a loss or tie if one happens.
Need a small hint?
random.randint(1, 12) can return any whole number from 1 through 12, including both ends. A bigger die can still roll a small number.
Ready for a stretch?
Restore equal dice and use a supplied for-loop pattern to record ten rounds. Count wins, losses, and ties; explain why ten rounds do not establish an exact long-run win rate.

Build a bounce wall

YOUR MISSION

At the right wall, should vx point right or left? What sign would make x decrease?

    
CHANGE ONE THING
Change only the right-wall assignment from vx = abs(vx) to vx = -abs(vx). Keep the left-wall assignment unchanged.
Need a small hint?
abs(vx) is a nonnegative speed. -abs(vx) makes it negative. Adding a negative change makes x smaller.
Ready for a stretch?
