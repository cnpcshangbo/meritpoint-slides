Python 动手体验课：教师少讲，学生多试

50 分钟 · 零基础小班 · 英文学生任务、中文教学提示

围绕同一个足球尝试数据故事：预测 → 运行 → 改一处 → 再运行 → 解释。所有数据均为虚构教学数据；本课不据此评价真实球员能力，也不训练 AI 模型。

课堂节奏

  • 开场立即运行程序，第 3 分钟前让每位学生看到自己修改后的输出。
  • 每次全班讲解最多 90 秒，通常只示范 30–60 秒；随后把键盘交回学生。
  • 先给独立预测时间，再听两种答案；不要先公布结果再让全班复述。
  • 一人一设备时每个人都操作；两人共用时按阶段交换“操作员”和“预测检查员”，不让熟练学生一直代打。
  • 用具体证据判断进度：运行结果、一个可指认的修改、学生自己的解释。完成勾选或在线状态不能代替学习证据。
  • 最后每位学生说 30 秒，保留 2–3 分钟下载与核对个人成果。

课前 5 分钟检查

  • 打开学生链接并试运行首个程序，检查键盘输入和浏览器 Python 加载。
  • 在“Compare fairly”提前试运行一次图表，确认 Matplotlib 可用；不要在学生首次操作前讲解整个绘图库。
  • 准备一个学生设备故障时的搭档方案和纸笔预测卡。
  • 如使用实时课堂，创建本实验课对应的课堂，说明学生可自愿加入、随时停止。AI 同意是另一项可选设置。
  • 确认“停止运行”、重试、下载与重新打开文件的流程。学生不用安装 Python，也不需要先注册才能做练习。

可选游戏任务：只选一个，不加进主线进度

提前完成的学生可以在原有练习时间内挑一个 3–5 分钟任务，或留到课后；保留最后分享与保存的时间。游戏任务按 3–5、8–12、12–20 分钟分三档，学生改一处参数或规则，并用实际画面和变量解释变化。不用游戏得分或反应速度评价学习。

0–3 分钟 · 3 分钟

1. Make it yours

0–3 分钟：一打开就请学生按 Run，目标是第 3 分钟前人人完成真实运行。不要先讲机构、安装或语法定义。学生改实验室昵称，不必输入真名。提问“你改了哪里？结果哪里变了？”每人指一下自己的输出即可。课前提前打开并检查 Python 加载；加载慢时先让学生预测，不能把示例输出说成已运行结果。

学生任务
Press Run Python now. Then replace Soccer Lab with a team nickname or a made-up lab name. Keep the quotation marks and parentheses.
先预测
What exact words will appear after your edit?
只改什么
Change only the words inside the quotation marks. Run again.
可观察的完成证据
Your output shows your own message, not the starter message. Point to the code you changed.
遇阻时给的一条提示
The words belong inside "quotes". print(...) displays them in the output.
提前完成的学生
Add a second print(...) line with a question your lab could investigate.

3–9 分钟 · 6 分钟

2. Predict a score

3–9 分钟：先静默预测 20 秒，再运行、改一个数字、再运行。只解释赋值、除法和 print 的用途，不展开类型、浮点或运算优先级。检查实际两次输出 60 与 80。不要代替学生打字；若两人共用电脑，在本阶段换操作者。

学生任务
This invented practice has 3 goals in 5 attempts. Predict the result, then run. Change goals to 4 while keeping attempts at 5.
先预测
Will the first result be 3, 5, or 60? What will it become with 4 goals?
只改什么
Change goals = 3 to goals = 4. Keep attempts = 5. Run a second time.
可观察的完成证据
You observed 60.0% and then 80.0%. Explain which number changed and which stayed the same.
遇阻时给的一条提示
/ means divide. The names help us read goals ÷ attempts × 100. Spaces around the printed % are fine.
提前完成的学生
Choose another valid goals value from 0 to 5. Predict first, then check.

9–16 分钟 · 7 分钟

3. Let the list count

9–16 分钟：让学生用手指点五个记录，再观察 sum 和 len。核心只需能解释“零也算一次尝试”。先运行原始数据，再做实验 A：替换一个 0，检查 4/5=80%。可选逐步可视化不超过 60 秒，不能挤掉动手时间。本阶段保留实验 A 的代码；下一阶段是从原始五次开始的独立实验 B。

学生任务
Each item is one invented attempt: 1 means goal; 0 means miss. Count by hand, then let Python check. Experiment A: replace one miss with a goal.
先预测
For [1, 0, 1, 1, 0], how many goals and attempts are there? Does replacing a 0 change the number of attempts?
只改什么
Replace exactly one 0 with 1. Do not add or delete an item. Run again.
可观察的完成证据
The starter prints 3 goals, 5 attempts, 60.0%. Your edit prints 4 goals, 5 attempts, 80.0%.
遇阻时给的一条提示
sum(shots) adds the values. len(shots) counts all the items, including zeros. Keep commas between items.
提前完成的学生
Use Visualize code to find the steps where goals and attempts receive their values. Explain why they are different.

16–24 分钟 · 8 分钟

4. Fix it, then test a new shot

16–24 分钟：先正常触发一次 NameError，告诉学生错误是线索，不是失败。援助顺序：读末行→指出名字→比较定义和使用；最后才给出改法。修好后先核对 3/5=60%，再添加 , 1，核对 4/6≈66.7%。明确实验 A 是替换一次结果，实验 B 是增加一次尝试。不要把 66.7% 与 80% 的区别解释成 Python 出错。

学生任务
This new starter uses the original five attempts. One variable name is wrong on purpose. Run it, read the final error line, and compare the names. Then try Experiment B: add one new goal.
先预测
After the repair, will the original data give 60% again? If you add a new goal, will the result be 80%, or will the total attempts also change?
只改什么
First change goal to goals on the rate line and run. Then add , 1 before the closing ] and run again.
可观察的完成证据
You repaired the NameError. After adding a goal, the output is 4 goals, 6 attempts, 66.7%: adding an attempt differs from replacing a result.
遇阻时给的一条提示
Python needs the same name each time: goals has an s. A new list item increases len(shots), too.
提前完成的学生
Explain this claim: “One extra goal always makes the rate 80%.” Use the two experiments as evidence.

24–34 分钟 · 10 分钟

5. Compare fairly

24–34 分钟：先请学生指出“4 个球比 3 个球多”，再问“总共试了几次？”检查 60% 对 40%，修改后 60% 对 50%。Matplotlib 是提供的工具，不要求学生默写 import、bar 或解释全部绘图代码；讲解至多 60–90 秒。图从真实运行结果产生，纵轴固定 0–100%，文字输出也要保留，方便老师查看自愿共享的代码和结果。明确这是人为编的数据，不能证明距离导致成绩变化。

学生任务
These are two invented groups, not real player measurements. Count goals and attempts in each. Run the provided chart scaffold. Then change one miss to a goal in the 9 m group.
先预测
The 9 m group has more goals. Must it also have the higher success rate? Predict both bar heights.
只改什么
Change exactly one 0 to 1 in far. Keep the near list and the number of far attempts unchanged. Run again.
可观察的完成证据
First: 3/5 = 60% at 3 m; 4/10 = 40% at 9 m. After your edit: 5/10 = 50% at 9 m. Both printed numbers and the chart agree.
遇阻时给的一条提示
Compare goals divided by attempts, not goals alone. Edit only a list value; the supplied plotting lines build the chart.
提前完成的学生
Predict how adding one new goal to the original far list differs from replacing a miss. Test 5/11 ≈ 45.5% on a fresh copy.

34–44 分钟 · 10 分钟

6. Run your own mini experiment

34–44 分钟：学生自己选问题、先记预测、运行两次；老师巡视提问而不是逐行带抄。核心答案供核对：原始 3/5=60%；追加进球 4/6≈66.7%；追加未进球 3/6=50%；替换一个未进球 4/5=80%。不要统一指定每个人同一种修改。检查代码、文字结果和图是否来自同一次最后运行；编辑后尚未重跑要标明结果过期。共享为自愿，未加入实时课堂的学生可直接展示自己的设备。

学生任务
Choose a question: What happens if I add a goal, add a miss, or replace a miss? Run the unchanged baseline once. Write your prediction. Then edit only test and give experiment a matching title. Run again.
先预测
State your planned edit and predicted rate before the second run. Which values will you keep unchanged?
只改什么
Keep baseline unchanged. Make one chosen edit to test and change the experiment title to describe that edit.
可观察的完成证据
You ran before and after your edit. Your final code, text output, chart, and written finding describe the same test. Include both goals and attempts in the finding.
遇阻时给的一条提示
Choose one: add , 1; add , 0; or replace one 0 with 1. A title is a label: changing only the title does not test the data.
提前完成的学生
Try a second question in a separate saved copy. Explain why equal goal counts can still produce different percentages.

44–50 分钟 · 6 分钟

7. Show what you found

44–50 分钟：每人约 30 秒分享，五人约 2 分半，余下时间完成反思和下载。提问“哪一个决定是你自己做的？”不按打字速度或谁最早完成排序。个人成果应包含实际编辑的代码、对应最后运行结果、预测和一句限制；不能下载公共 starter 冒充个人作品。图可选单独保存。结束前确认下载确实成功；不要求发到群里、开启 Zoom 屏幕共享或同意 AI 分析。

学生任务
Use your completed mini experiment. Finish: “I predicted…”, “I changed…”, “I found…”, and “This does not prove…”. Give a 30-second explanation, then download your work.
先预测
If a partner opens your saved code, what result should they see?
只改什么
Add a finding with your actual goals, attempts, and percentage. Add one limitation. Keep the final code and result from your own experiment.
可观察的完成证据
Your saved artifact includes your question or title, prediction, edited code, actual result, and limitation. You can identify your own edit and explain it without reading every line.
遇阻时给的一条提示
Example structure: “I added a miss. The rate changed from 3/5 = 60% to 3/6 = 50%. These invented shots do not tell us a real player’s ability.” Use your own result.
提前完成的学生
Name one additional piece of evidence you would collect in a real study, such as more attempts or repeated sessions.

巡视时的三个问题

  1. “你原来预测会出现什么？”
  2. “你只改了哪里？哪些东西没有改？”
  3. “哪一行输出支持你的解释？”

援助阶梯：让学生读最后一行错误 → 指出相关一行 → 比较正确与错误的名字或符号 → 必要时给一条最小修复提示。每次提示后仍由学生自己编辑并重跑。

核心活动优先。卡住时先完成一个有效修改和解释，暂不做 stretch；提前完成者做第二次预测与检验，不替别人完成任务。

技术故障与成果核对

  • 运行时加载慢：明确显示加载状态，学生先写预测；可换到同伴设备轮流执行。不要把预填数字显示为学生运行成功。
  • 图表包不可用：保留文字数值输出，先进行同样的比较；可手画 0–100% 柱状图，并注明是手画图。代码没有执行时，成果必须注明“仅预测／手算”。
  • 断网或无法运行：用纸笔数 1、数所有项、计算比例，留下预测与计算过程；恢复后再用 Python 验证。
  • 最终成果至少包括：个人问题或标题、预测、实际修改后的代码、对应运行结果、一个发现和一个限制。不能用公共 starter 或旧运行结果替代。
  • 真实图表和打印结果应匹配最后一次成功运行。最后一次编辑后没有重跑时，先重跑再保存，或明确标记“未验证的修改”。
  • 实时课堂只共享自愿提交的当前代码与文字结果，不传学生完整屏幕。教师看到文字结果不等于看到了图表；请学生口述图形，必要时自愿展示设备。
  • 不要求 Zoom 屏幕共享，不强制 AI 同意，不要求学生公开姓名或分享私人文件。

可直接让学生读的收尾句：“I changed ____. My result was ____. This does not prove ____.”
